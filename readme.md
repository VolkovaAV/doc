Подготовка к использованию исходного кода:

Нужен **Python 3.11 или новее**. Для конвертации в PDF (docx2pdf) нужен установленный Microsoft Word, поэтому генерация работает только на Windows и macOS.

1. Открыть `config.py` и проверить правильность всех постоянных величин (почта, реквизиты, подписант).

2. Задать пароль от почты отправителя. Пароль не хранится в репозитории. Способы на выбор:

    - скопировать `config_local.example.py` в `config_local.py` и вписать пароль в `FROM_PASSW` (файл `config_local.py` игнорируется git);
    - или задать переменную окружения `DOCAPP_MAIL_PASSWORD`.

    Для mail.ru нужен «пароль для внешних приложений» из настроек безопасности ящика.

3. Создать окружение (только при первом запуске):
    
    ```python -m venv venv```

4. Активировать окружение:

    Windows PowerShell

    ```Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope Process```
    ```.\venv\Scripts\Activate.ps1```
    
    Linux / macOS

    ```source venv/bin/activate```

5. Установить зависимости (только при первом запуске)

    ```pip install -r requirements.txt```

6. Собрать исполняемый файл (необязательно):

    ```pyinstaller --onefile --windowed --name DocApp --add-data "GDocument/ver_02.png;GDocument" --add-data "GDocument/email.html;GDocument" --add-data "config.json;." main.py```

    На macOS/Linux в `--add-data` вместо `;` используется `:`. Если используется `config_local.py`, он попадёт в exe при сборке, поэтому не передавайте такой exe третьим лицам.

Как пользоваться:

1. Запустить DocApp.exe (если собирали исполняемый файл) или ```python main.py```.
2. Нажать кнопку: "Создать шаблоны". Выскочит окно с необходимыми для шаблонов параметрами. Заполнить все поля, нажать "ОК".

    - Краткое название мероприятия (н-р, NPW-2025).
    - Полное название мероприятия в ПРЕДЛОЖНОМ ПАДЕЖЕ (вопрос: "в чём?") без предлога (н-р, V Международном симпозиуме "Актуальные проблемы нелинейной волновой физики")
    - Даты проведения в свободной форме (н-р, 7–13 сентября или 7 сентября – 13 сентября)
    - Место проведения в свободной форме (н-р, г. Москва)
    - Ссылка на публичную оферту (н-р, ссылку на ЯндексДиск)

    После завершения появятся сообщения об успешном создании шаблонов. При повторном нажатии кнопки поля заполнены последними введенными параметрами.
    В рабочей папке появится файл `participant_list.xlsx` - рабочий файл откуда программа будет подгружать информацию об участниках.
    Появится папка templates. Появятся файлы: `templates/bill.docx` - шаблон счета, `templates/email.html` - шаблон электронного письма. Их желательно не изменять.

    ```
    !!! Ключи внутри шаблона счета (синтаксис docxtpl/Jinja): !!!
    {{ LAST_NAME }}
    {{ FIRST_NAME }}
    {{ MIDDLE_NAME }}
    {{ SUMM }}
    {{ FILENAME }}   - сюда вставляется QR-код

    Дополнительно доступны: {{ SEX }}, {{ SUMM_NAME }}, {{ F_NAME }}, {{ M_NAME }}

    Ключи в шаблоне письма: ${EVENT_NAME}, ${OFERTA_LINK}, ${ORG_NAME},
    ${SEX}, ${FIRST_NAME}, ${MIDDLE_NAME}
    ```

    Текст письма хранится в `GDocument/email.html` - его можно править как обычный HTML.
    После изменения нажмите "Создать шаблоны", чтобы обновить `templates/email.html`.

3. Заполнить данные участников. В файле `participant_list.xlsx` необходимо заполнить следующие столбцы:
    * Фамилия, Имя (обязательно), Отчество (если есть)
    * Сумма - целое число рублей
    * email

4. Нажать кнопку "Сгенерировать". Это довольно длительный процесс, кнопки будут недоступны до его окончания. По окончанию процесса появится сообщение об успешной генерации. По завершению появится папка `files`. Внутри можно найти все сгенерированные файлы (в том числе старые). Важно понимать, что при нажатии на кнопку "Сгенерировать", старые файлы могут перезаписаться.
5. Нажать кнопку "Рассылка". После ее нажатия появится окно с выбором: отправить тестовую рассылку или отправить готовую рассылку. Получатели рассылки формируются из `participant_list.xlsx`.
    - "Тестовое письмо" - письма для ВСЕХ участников отправляются на тестовый email (`TO_MAIL_TEST` в `config.py`).
    - "Отправить рассылку" - после подтверждения письма отправляются участникам по списку `participant_list.xlsx`.

    При любом типе рассылки все письма также сохраняются в папку "Отправленные" в аккаунте-отправителе. В истории выводится, кому письмо отправлено и какие письма отправить не удалось.

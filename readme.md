Подготовка к использованию исходного кода:

1. Открыть config.py и проверить правильность всех постоянных величин:

2. Создать окружение:
    
    ```python -m venv venv```


3. Активировать окружение:
    
    Windows
    ```.venv\Scripts\activate.bat```
    
    Linux
    ```source .venv/bin/activate``

4. Установить зависисмости

    ```pip install -r requirements.txt```


5. Собрать исполняемый файл (необязательно):

    ```pyinstaller --onefile script.py```

Как пользоваться:

1. Запустить DocApp.exe (если собирали исполняемый файл) или ```python3 main.py```.
2. Нажать кнопку: "Создать шаблоны". Выскочит окно с необходимыми для шаблонов параметрами. Заполнить поля, нажать "ОК".

    - Краткое название мероприятия (н-р, NPW-2025).
    - Полное название мероприятия в ПРЕДЛОЖНОМ ПАДЕЖЕ (вопрос: "в чём?") без предлога (н-р, V Международном симпозиуме "Актуальные проблемы нелинейной волновой физики")
    - Даты проведения в свободной форме (н-р, 7–13 сентября или 7 сентября – 13 сентября)
    - Место проведения в свободной форме (н-р, г. Москва)
    - Ссылка на публичную оферту (н-р, ссылку на ЯндексДиск)

    После завершения появятся сообщения об успешном создании шаблонов. При повторном запуске программы сохраняются последние введенные параметры мероприятия.
    В папке рядом с DocApp.exe появится файл `participant_list.xlsx` - рабочий файл откуда программа будет подгружать информацию об участниках.
    Появится папка templates. Появятся файлы: `templates/bill.doc` - шаблон счета, `templates/act.doc` - шаблон акта, `templates/email.txt` - шаблон электронного письма. Их желательно не изменять.


    ```
    !!! Обязательные ключи внутри шаблонов: !!!
    {LAST_NAME}
    {MIDDLE_NAME}
    {FIRST_NAME}
    {SEX}
    {SUMM}
    {SUMM_NAME}
    {F_NAME}
    {M_NAME}
    {LAST_NAME}
    {FILENAME}
    ```

3. Заполнить данные участников. В файле `participant_list.xlsx` необходимо заполнить следующие столбцы:
    * ФИО (Фамилия, Имя, Отчество)
    * Сумма оплаты
    * email

4. Нажать кнопку "Сгенерировать". Это довольно длительный процесс. Программа не будет "отвечать" пока не закончится генерация. По окончанию процесса появится сообщение об успешной генерации. По завершению появится папка `files`. Внутри можно найти все сгенерированные файлы (в том числе старые). Важно понимать, что при нажатии на кнопку "Сгенерировать", старые файлы могут перезаписаться.
5. Нажать кнопку "Рассылка". После ее нажатия появится окно с выбором: отправить тестовую рассылку или отправить готовую рассылку. Важно, что получатели рассылки формируются из `participant_list.xlsx`. Тестовая рассылка означает отправку ВСЕХ файлов на тестовый email. Кнопка "Рассылка" отправляет письма по списку `participant_list.xlsx`. При любом типе рассылки все  письма также должны сложиться в папку "Отправленные" в аккаунте-отправителе.
